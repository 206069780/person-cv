# Review Plan

## 是否需要独立评审

需要

## 原因

- 产物同时包含 3D 网页、移动降级、Docker/Nginx、DOCX 和 10 页 PDF，文件和验证面较广。
- 简历中的事实归属、量化边界和项目归属必须保持一致。

## 评审类型

- 文档事实与表述评审
- 网页视觉与交互评审
- 部署与性能评审

## 评审输入

- `design.md` 与 `plan.md`
- 网页测试、构建输出和桌面/手机截图
- 最终 DOCX、PDF、PDF 文本提取结果和十页渲染图
- `git status`，用于确认未提交简历相关内容

## 通过标准

- 网页采用批准的 B 方案，桌面 3D 非空且移动降级完整。
- PDF 恰好 10 页、文本可检索、内容无截断或乱码。
- 立升、Litree、10,000+ 水站、WeLink、森格、OA/HR 和 Agent 内容符合已确认边界。
- 不出现未经确认的设备数、并发量、性能提升比例、项目金额和团队人数。
