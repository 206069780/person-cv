# 简历网页工程终端

## 描述

在现有高级 Java 开发工程师 3D 简历展馆首屏加入三窗口工程终端，以可交互的静态履历证据展示 Java 后端、AIoT 协议接入与 Agent 工程化实践，同时保留现有展馆、项目导航与移动端简历。

## 影响模块

- `web/src/components/`：新增工程终端组件
- `web/src/data/`：新增有事实来源约束的终端命令数据
- `web/src/styles.css`：加入终端布局、状态与响应式样式
- `web/src/App.tsx`：将终端接入展馆首屏状态

## 验收标准

- [ ] 首屏提供 Java、AIoT、Agent 三组错层终端窗口，并与现有工业展馆视觉一致
- [ ] 支持预设命令切换、输出展开和键盘操作，交互状态有清晰反馈
- [ ] 所有文案来自既有简历事实，明确 `10w+` 为国内外水站项目覆盖规模，不伪造实时监控指标
- [ ] 协议接入内容区分个人负责与团队平台实践
- [ ] 打开项目详情时终端不会遮挡内容，移动端继续使用完整简历与电脑端最佳体验提示
- [ ] `prefers-reduced-motion` 下关闭打字与连续装饰动画
