# 简历网页工程终端设计

## 目标

在现有 3D 数字简历展馆的首屏 HUD 中增加三个错层工程终端窗口，用项目证据展示 Java 后端、AIoT 协议接入与 Agent 工程化实践。终端是履历浏览器，不模拟生产运维系统。

## 内容边界

- 固定标注 `CAREER EVIDENCE · STATIC DEMO`，所有输出均为静态履历证据。
- `10w+` 仅表述为 Litree 面向国内外水站的项目覆盖规模，不写在线数、设备数或实时连接数。
- Java 窗口可切换 Litree 平台总览、OA/HR 同步、华为 WeLink 数据链路。
- AIoT 窗口明确区分个人负责的有人云组件与团队 MQTT、Modbus、TCP/UDP、OPC/HTTP 等协议实践。
- Agent 窗口展示 AgentScope Java 2.0 适配、Spring AI Alibaba Graph、Tool/MCP、HITL、RAG 和 AI Coding 三态流程。
- 不出现 QPS、延迟、吞吐、成功率、可用性、性能提升比例、项目金额或团队人数。

## 交互结构

- 桌面端在 HUD 右侧放置三扇半透明工业终端，未聚焦窗口保留错层轮廓，顶部模式切换按钮负责聚焦，避免重叠窗口形成不可点击区域。
- 每扇窗口提供 1 至 3 个预设命令按钮。命令不是自由输入框，点击后直接切换完整、可审计的项目输出。
- 输出行一次性写入 DOM，通过短促的逐行显现营造终端感，屏幕阅读器可立即读取完整内容。
- “查看对应展区”使用命令携带的展区 ID 打开既有项目面板；面板打开后终端自动隐藏。
- 桌面终端仅在 `!loading && !introActive && activeExhibit === null` 时显示。
- 手机降级页在个人概览后加入单窗口切换版本，默认显示 Java，保留原有“电脑端最佳体验”提示和完整纵向简历。

## 视觉系统

- 沿用展馆已有深色工业令牌：背景 `#081117`、信号青绿 `#00a89d`、信息青 `#28d7e5`、安全橙 `#ff6b3d`。
- 终端使用 1px 金属边框、4px 以内圆角、硬边阴影和轻量背景模糊；不使用紫色 AI 渐变、装饰光球或新增粒子。
- 标题和命令使用 `IBM Plex Mono / Consolas`，正文继续使用现有中文无衬线字体。
- 微交互保持 150-300ms；光标闪烁只播放有限次数，不设置持续装饰动画。

## 可访问性与性能

- 模式按钮和命令按钮使用真实 `button`、可见焦点和 `aria-pressed`。
- 输出区使用 `aria-live="polite"`，窗口标题与静态演示标签提供明确语义。
- `?mode=reduced` 与 `prefers-reduced-motion` 都禁用入场、逐行显现和光标动画。
- 终端位于 DOM HUD，不进入 Three.js Canvas，不新增依赖或渲染循环。

## 验证范围

- 一个 Vitest 文件覆盖三组终端、命令/展区引用、事实边界及 reducer 状态切换。
- TypeScript 检查与生产构建。
- 1440px、1024px、390px 三个视口和 reduced-motion 模式的视觉检查。
