# 简历视觉升级设计说明

## 1. 目标与边界

本次迭代同时升级 10 页正式投递 PDF 与可部署的 3D 网页展馆。两端继续共用 `resume-data.json`，只调整表达与视觉，不改变已经确认的公司、日期、职责和项目事实。

硬性边界：

- 目标岗位保持“高级 Java 开发工程师”。
- 立升净水科技保持 `2023.10 至今`，Litree 保持“国内外 10w+ 水站”。
- Litree 六个专题仍属于同一个项目。
- 不新增设备数、并发量、性能提升比例、项目金额或团队人数。
- 不使用数字人、语音介绍、视频背景或大体积外部 3D 模型。

## 2. 统一视觉语言

设计关键词为“工业数字孪生、工程案例、可信、精密、克制的高能感”。

色彩系统：

- 石墨黑 `#081117`：网页空间与 PDF 封面主底色。
- 矿物青 `#00A89D`：水务、在线状态与章节主色。
- 冷光青 `#28D7E5`：数据流、交互焦点与空间深度。
- 安全橙 `#FF6B3D`：关键数字、入口、主操作与风险边界。
- 冷白 `#F5F8F9`：PDF 正文纸面与网页主文字。
- 钢灰 `#62727D`：次要信息、边界线与技术标签。

网页与 PDF 不照搬同一种背景。网页以深色空间叙事为主，PDF 以白底正文和深色章节锚点为主，二者通过同一套色彩、编号和线性图形保持一致。

## 3. PDF：工程案例册

### 3.1 总体结构

保持 A4 纵向、恰好 10 页、文本可搜索：

1. 深色封面：姓名、岗位、10w+ 水站、四项核心能力与联系方式。
2. 核心简历：能力矩阵、三段经历、技术域索引。
3-8. Litree 同一项目的六个专题案例页。
9. 华为 WeLink。
10. 森格智慧水务平台 0-1。

### 3.2 页面构成

封面使用非对称构图：左侧窄编号轨道、中央姓名与岗位、右下角 `10w+` 数据锚点，并用细线管网和小面积安全橙形成工业识别度。装饰只使用矢量线、实心几何和文字，不使用位图背景。

正文页使用“章节轨道 + 案例主区 + 交付链路 + 技术底栏”：

- 左侧 12-16 mm 章节轨道显示页码、专题编号和项目归属。
- 顶部用大标题和短摘要建立页面主题，不重复普通页眉。
- 项目定位、本人角色、工程边界使用三段横向信息带。
- 项目背景不再使用一句话概括，按“业务场景 → 现有痛点 → 建设目标”展开为 2-3 个短段落；Litree 六个专题共享项目级背景，再分别补充专题问题，避免六页重复同一段文字。
- 业务链路绘制为可搜索文字节点与连接线，不将文字栅格化。
- 核心实现和技术难点采用两栏或主次分区，避免整页单列文字堆在上半页。
- 落地结果使用深色横条收束，技术栈使用紧凑标签矩阵。

### 3.3 可读性与 ATS

- 正文字号不低于 8.8 pt，重要正文保持 9.2-10 pt。
- 中文使用 Microsoft YaHei，英文保持统一无衬线体系。
- 正文底色保持白色或接近白色，深底只用于封面、章节轨道和小面积结果条。
- 所有正文、数字和标签均由 ReportLab 直接绘制为文本。
- 不使用透明度过低的正文、复杂表格、照片、二维码或装饰性图标字体。

## 4. HTML：工业数字孪生增强版

### 4.1 空间升级

保留全屏 Three.js 展馆和八个热点，将现有线框空间升级为可辨识的工业场景：

- 中央馆：大型水务数据核心、环形步道、悬浮项目铭牌与水面反射区。
- 设备馆：泵组、立管、阀门轮廓和纵向状态灯，强化尺度参照。
- AIoT 馆：协议入口门阵、报文脉冲和物模型汇聚节点。
- GIS/DMA 馆：地面管网拓扑、区域边界、压力/流量脉冲。
- OA/HR 馆：组织层级格栅、同步批次轨道和审批状态线。
- Agent 馆：更高强度冷光、工具调用轨道、Graph 节点和 HITL 安全闸。
- WeLink 与森格馆：分别呈现搜索索引流和 0-1 水厂监控链路。

场景继续使用程序化几何和标准 PBR 材质。通过金属粗糙度、局部面光、雾深、接触阴影、反射色和高低层结构增强真实感，不引入无法控制体积的外部模型。

### 4.2 动画与镜头

- 入场保持 6-8 秒，可随时跳过和被用户输入中断。
- 镜头依次经过入口闸门、地下管网数据流、中央核心和展馆全景。
- 数据流沿明确管线移动，不使用无来源的漂浮光球或全屏粒子噪声。
- 热点聚焦时只强化当前展馆的灯光、路径和铭牌，其余区域降低亮度。
- UI 过渡控制在 180-320 ms；空间镜头可使用 600-1200 ms 缓动。
- `prefers-reduced-motion` 下关闭入场、漂移、脉冲和镜头动画。

### 4.3 HUD 与项目面板

- 顶部仅保留身份、10w+、返回中央馆和 PDF 下载。
- 底部展馆索引升级为轨道式导航，当前展馆显示进度条、编号和状态，不使用重复卡片。
- 项目详情面板增加“业务链路”与“工程边界”，首屏优先展示角色和结果。
- 项目背景采用渐进展开：摘要层显示业务场景与建设目标，深度层补充数据来源、跨系统关系和该专题需要解决的问题；内容与 PDF 同源。
- 图标继续统一使用 Lucide，图标按钮保留可见焦点与工具提示。
- 面板打开时自动降低场景交互强度，避免 HUD、索引和正文重叠。

### 4.4 手机端与降级

- 宽度小于 768 px 首次进入显示“建议使用电脑端浏览，以获得完整 3D 展馆体验”。
- 确认后进入完整纵向简历，不加载 Three.js 场景。
- WebGL 不可用时进入同一纵向简历。
- 手机端触控目标不小于 44 px，无横向滚动，PDF 下载和联系方式始终可达。

### 4.5 性能策略

- Three.js 继续动态导入，首包不直接包含场景代码。
- 仅使用少量程序化纹理、实例化几何和共享材质。
- 根据设备能力限制像素比、阴影尺寸、数据流数量和反射效果。
- 动画更新集中在 `useFrame`，避免 React 高频状态更新。
- 单个展馆视觉失败时保留 HUD 和文本；场景初始化失败时自动降级。

## 5. 验证标准

- PDF 恰好 10 页，逐页渲染检查无截断、重叠、乱码和不可读低对比文字。
- PDF 能提取姓名、岗位、立升、10w+、WeLink、森格、OA/HR 和 Agent 关键文本。
- 桌面端 1440x900 与 1920x1080 下场景非空、构图完整、无 UI 重叠。
- 手机端验证提示、纵向简历、PDF 下载、触控尺寸和无横向滚动。
- 验证完整展馆、减少动态、WebGL 降级和项目面板状态。
- 只运行核心事实、体验模式、生产构建与视觉检查，避免扩展无关测试。

## 5.1 项目背景扩展口径

### Litree 智慧水务云平台

背景需要说明：平台面向国内外 10w+ 水站，业务同时连接 OA 站点主数据、项目空间、水站、现场网关、IoT 设备、工艺监控、告警运维、GIS 管网和数据分析。不同业务对象分布在多个微服务和外部系统中，需要统一身份、租户、权限、标识映射和数据协作机制。六个专题在此共同背景下，分别展开设备数据、多协议接入、GIS/DMA、OA/HR 和 Agent 工程化问题。

### 华为 WeLink

背景需要说明：WeLink 面向中大型企业和高校提供协同办公能力，小薇搜索需要跨人员、群组和聊天记录提供统一检索，同时结合画像、个性化、推荐、纠错和意图识别。搜索数据同时存在实时变更、历史存量和链路缺失补偿场景，因此需要 Kafka/Flink 实时接入、Hadoop/Hive/Spark 离线处理与 Elasticsearch 搜索侧形成统一数据口径。

### 森格智慧水务平台 0-1

背景需要说明：水厂业务需要把现场设备、服务端和客户端连接起来，从设备数据采集、状态处理、实时监控和告警延伸到水质水压报表、数据归档、远程控制和上线运维。项目处于 0-1 建设阶段，需要同时完成基础权限、核心业务、实时数据链路、部署交付和生产问题处理，形成可运行的完整业务闭环。

## 6. 设计自审

- 无 TBD、TODO 或未决视觉方向。
- PDF 与网页共享事实，但采用不同媒介表达，不互相照搬。
- “炫酷”集中在空间、光照、材质、镜头和数据叙事，不以紫色渐变、装饰光球或持续抖动替代设计。
- 视觉升级不改变项目归属、个人职责边界和已确认量化信息。
