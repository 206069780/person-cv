# PDF 首页中间件线框矩阵设计

## 背景与目标

当前 PDF 首页的十个核心能力线框结束于约 `y=321pt`，底部职业定位终端框从 `y=220pt` 开始，两者之间存在约 `101pt` 的连续空白。此次在该区域增加一组中间件能力线框，使首页信息密度更完整，同时保持现有工业工程视觉与清晰的阅读层级。

## 内容与信息层级

新增区域不设置独立标题，直接使用两行双列矩阵：

1. `Redis Cluster` 与 `RabbitMQ`
2. `Nacos` 与 `Sentinel`

最终线框只显示 `Redis Cluster`、`RabbitMQ`、`Nacos`、`Sentinel` 四个组件名称，不再显示类别前缀。内容仅添加在 PDF 首页绘制逻辑中，不修改共享简历数据，也不影响 DOCX 首页内容结构。

## 布局与视觉

- 沿用现有双列宽度 `236pt`、列间距 `15pt` 和左右边界 `54pt / 541pt`。
- 两行线框完整落在 `y=224pt` 至 `317pt` 之间，上下均保留约 `4pt` 至 `5pt` 的分隔空间。
- 每个线框高 `42pt`、行间距 `9pt`，与上方核心亮点线框尺寸完全一致。
- 线框沿用上方的深色底、低亮度描边、`4.5pt` 左侧高亮色条和粗体文字，不再增加信号节点或额外类别标签。
- 强调色在青绿、亮青和安全橙之间轮换，四个组件名称均保持单行且不越界。

## 约束

- 不移动或缩小职业定位终端框、联系方式和页脚。
- 不修改第 2 至 9 页绘制逻辑。
- 不改动用户现有简历数据及并行中的 Web 页面修改。
- PDF 和 DOCX 继续由同一生成脚本一次性生成，但新增视觉只作用于 PDF 首页。

## 验收标准

- 首页原有大块留白由两行双列中间件线框完整填充，且没有独立区域标题。
- 新增线框与上方十个核心亮点对齐，并在上方矩阵和底部职业定位框之间各保留约 `4pt` 至 `5pt` 的可见分隔。
- 四个技术名称无截断、重叠或越界。
- PDF 仍为 9 页，后续页面视觉和分页不变。
- 重新生成的 DOCX 可正常打开，PDF 可正常解析和渲染。

## 自检

- 需求覆盖：四个中间件、两行双列、移除独立标题和线框尺寸统一均已明确。
- 范围控制：仅修改首页 PDF 绘制区域，不触碰共享数据和其他页面。
- 可实现性：`101pt` 留白可容纳两个 `42pt` 线框行、一个 `9pt` 行距及约 `9pt` 的上下分隔空间。
