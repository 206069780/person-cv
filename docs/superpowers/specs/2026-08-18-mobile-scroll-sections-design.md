# 移动端首页模块化滚动交互设计

## 背景与目标

当前桌面端使用全屏 3D 展馆，移动端和 WebGL 降级模式使用同一套纵向简历。此次仅调整移动端纵向简历，不改变桌面 3D 展馆、简历数据、工程终端业务交互及下载与联系方式。

目标是让纵向简历具有清晰的章节边界，并在滚动进入章节时呈现克制的科技感反馈。视觉效果必须服务于信息层级，不得阻碍快速浏览、文本阅读或辅助技术访问。

## 信息架构

页面按以下顺序分为独立章节：

1. 个人信息 Hero：姓名、职位、简介、项目规模及主要操作。
2. 工程终端：作为能力证据入口，与履历正文形成明显层级区分。
3. 工作经历：以纵向时间轴组织任职经历和成果。
4. 项目章节：每个项目单独成章，先展示项目背景、痛点和目标，再展示专题条目。
5. 页尾联系信息：作为页面结束状态，不参与复杂入场动画。

章节通过序号、边界线、背景明度变化和顶部状态标记区分，不将整段页面包装成浮动卡片，也不使用强制滚动吸附。

## 视觉语言

- 延续现有工业数字孪生风格，以深色背景、青绿色信号色和安全橙为主要视觉锚点。
- 项目章节在青色、绿色和安全橙之间轮换强调色，避免页面被单一蓝色主导。
- 页面顶部设置高度固定的细滚动进度条，随阅读进度连续更新。
- 章节边缘可使用短扫描线、刻度和数据线作为装饰，但不得穿过正文或降低文字对比度。
- 章节编号和标题是主要动效对象，正文动效更轻，以保证阅读稳定性。

## 滚动行为

### 章节揭示

章节首次进入视口约 20% 后触发一次揭示，顺序如下：

1. 章节边界线由短到长展开。
2. 章节编号和状态标记点亮。
3. 标题以轻微上移和淡入出现。
4. 正文与子项按层级错开进入，单项延迟保持短促。

章节离开视口后保持已揭示状态，返回上方时不重复播放，避免阅读过程中反复闪动。

### 模块特有效果

- Hero：向下滚动时轻微降低亮度并产生小幅纵向位移，不缩放正文，不影响操作按钮命中区域。
- 工程终端：首次进入时播放一次短扫描线和指示灯启动效果，现有标签及展开交互保持原样。
- 工作经历：时间轴主线先出现，各经历节点再按从上到下的顺序点亮。
- 项目章节：项目背景前导区先出现，专题条目随后依次揭示；长列表不等待全部动画完成即可阅读和滚动。
- 页尾：仅使用简单淡入和边界线收束，不增加持续动画。

## 组件设计

### ScrollReveal

通用容器负责观察元素是否进入视口，并暴露一致的已揭示状态。业务组件通过属性声明动效类型和延迟，不直接注册滚动监听。

行为约束：

- 使用 `IntersectionObserver`，触发后立即取消对该元素的观察。
- 服务端或测试环境缺少 `IntersectionObserver` 时，内容默认显示。
- 内容在任何状态下都保留于 DOM，动画不得作为读取内容的前置条件。
- `prefers-reduced-motion: reduce` 下跳过过渡并直接显示最终状态。

### ScrollProgress

固定在移动端页面顶部，读取文档可滚动距离并输出 0 到 1 的进度。滚动事件使用 passive listener，并通过 `requestAnimationFrame` 合并同一帧内的更新。页面尺寸变化时重新计算。

### MobileResume

保留现有数据映射，只增加章节语义容器、揭示包装和项目强调色索引。电话、邮件、PDF 下载及工程终端的交互行为不得改变。

## 样式与性能

- 动画主要使用 `transform` 和 `opacity`，避免对布局属性做逐帧动画。
- 动效距离保持在 8 到 20 像素范围，单段持续时间控制在 320 到 620 毫秒。
- 页面级滚动逻辑只允许一个进度监听器，章节触发由共享观察机制处理。
- 所有固定元素预留稳定尺寸，避免进度条或状态标记引发布局偏移。
- 动画类使用统一 CSS 变量管理持续时间、延迟、位移和章节强调色。

## 可访问性与降级

- 保持现有标题层级和章节 `aria-labelledby` 关系。
- 装饰元素均标记为不可访问，不向屏幕阅读器输出状态噪声。
- `prefers-reduced-motion: reduce` 下关闭扫描线、位移、错峰和 Hero 滚动响应。
- JavaScript 失败或观察器不可用时，所有内容必须保持可见。
- 顶部进度条作为纯视觉反馈，不播报连续变化的百分比。

## 验收与测试

自动化测试覆盖：

- `ScrollReveal` 默认渲染完整内容。
- 元素进入视口后切换为已揭示状态，并停止继续观察。
- 缺少 `IntersectionObserver` 时内容立即显示。
- 项目和工作经历数据仍全部输出，原有工程终端交互测试继续通过。

视觉验收覆盖 375px 和 430px 宽度，并检查：

- Hero、工程终端、工作经历、项目章节和页尾边界清晰。
- 首次向下滚动时动效顺序正确，快速滚动不会留下隐藏内容。
- 返回上方时章节不重复闪动。
- 长公司名、长项目标题和列表文本不溢出或互相遮挡。
- 减少动态效果模式下页面完整、稳定且无持续动画。
- 页面滚动流畅，固定进度条不遮挡正文或系统安全区域。

## 非目标

- 不将桌面 3D 展馆改为滚动页面。
- 不使用整屏吸附或劫持浏览器滚动行为。
- 不修改简历内容和项目数据。
- 不新增运行指标、在线状态或未经履历确认的数据展示。
